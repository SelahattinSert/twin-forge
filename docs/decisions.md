# Architecture decisions

- **MapAnything stays behind an adapter.** Its model loader, input preprocessing, output tensors, and OpenCV coordinate convention are confined to `MapAnythingBackend`; TwinForge core consumes normalized arrays and camera records.
- **PLY is authoritative and point based.** It preserves raw finite geometry plus a validity flag, confidence, and provenance without premature surface fusion. The GLB point primitive filters out points marked invalid for a cleaner viewer preview.
- **Keyframes trade novelty for continuity and timeline coverage.** Blur and exposure reject unusable observations; perceptual hashes remove near duplicates; ORB correspondence and displacement prefer useful changes while retaining overlap. When a configured cap is reached, a timestamp-spread subset preserves the full valid timeline instead of silently dropping its later segment; final-neighbor overlap is recomputed and reported.
- **Scale and confidence remain explicit.** MapAnything metric output is labeled estimated metric, and no scale or confidence certainty is fabricated. Physical-reference evaluation exposed remaining shape error; one-control calibrated metric does not certify whole-scene accuracy.
- **Memory budgets are automatic but explicitly heuristic.** The old default of 80 views exceeded the observed capacity of the 6 GiB GPU. Planning now uses free memory after weights load, configurable allowances, and a fallback cap of 32. It is not a universal peak-memory formula. CUDA inference OOM can halve/reload at most three times while preserving the minimum and timeline; every adjustment/attempt is recorded. We do not silently switch devices. XYZ payload preflight remains only a lower-bound diagnostic.
- **Candidate pixels are not retained for the whole video.** Disk-backed JPEGs are analyzed individually; compact descriptors/hash/quality records enable deterministic selection without holding gigabytes of candidate RGB arrays. This is bounded image residency, not constant total memory or disk usage.
- **Output health is not a geometry accuracy gate.** Quality explicitly states that geometric validation is unavailable. Synthetic adapter tests and real smoke invariants detect malformed output but cannot replace independent measured-distance benchmarks.
- **FFmpeg performs oriented decode.** FFmpeg applies stream rotation during video filtering; metadata retains both coded and display dimensions so sideways phone footage is not silently treated as unrotated.
- **Application semantics are excluded.** TwinForge models only observed physical geometry and reconstruction provenance.
- **Saved artifacts are a backend-independent boundary.** Viewer, measurement, and calibration work without model installation or inference. Read-only original PLY identities and source-image/artifact hashes bind exact observations; reduced display points cannot replace measurement data.
- **Uniform scale is the only calibration transform.** Two identified source views and complete pixel sensitivity must pass fixed engineering checks before physical input. A single positive scalar preserves shape errors and projection; source and historical artifacts remain intact. The control is excluded from other checks, and previously inspected checks are not blind tests.
- **Phone preprocessing is recorded explicitly.** Bounded aspect-preserving sharpness analysis does not resample saved keyframes. The versioned HDR Hable/sRGB path records filter assumptions and source/display/JPEG/model transforms separately; no unknown pixel mapping is invented.
- **Acceptance is bounded.** One planned pinned offline CPU CLI run uses at most 32 normally selected views with automatic budget and OOM retry disabled. One technical rerun is allowed only for a corrected concrete setup/implementation failure. Browser appearance and picking require actual browser evidence.
