# Phase 0 decisions

- **MapAnything stays behind an adapter.** Its model loader, input preprocessing, output tensors, and OpenCV coordinate convention are confined to `MapAnythingBackend`; TwinForge core consumes normalized arrays and camera records.
- **PLY is authoritative and point based.** It preserves raw finite geometry plus a validity flag, confidence, and provenance without premature surface fusion. The GLB point primitive filters out points marked invalid for a cleaner viewer preview.
- **Keyframes trade novelty for continuity and timeline coverage.** Blur and exposure reject unusable observations; perceptual hashes remove near duplicates; ORB correspondence and displacement prefer useful changes while retaining overlap. When a configured cap is reached, a timestamp-spread subset preserves the full valid timeline instead of silently dropping its later segment; final-neighbor overlap is recomputed and reported.
- **Scale and confidence remain explicit.** MapAnything metric output is labeled estimated metric, and no scale or confidence certainty is fabricated. Ground-truth accuracy remains unmeasured.
- **Memory preflight reports a lower bound, not a guessed peak.** The adapter estimates the documented float32 XYZ output payload from dimensions after MapAnything image preprocessing and compares it with currently free VRAM. It intentionally excludes model weights, activations, auxiliary output maps, and allocator overhead. Inference uses MapAnything's memory-efficient mode with dense-head minibatch size one. The configurable keyframe cap remains the direct control because a generally valid peak-memory formula is unavailable.
- **FFmpeg performs oriented decode.** FFmpeg applies stream rotation during video filtering; metadata retains both coded and display dimensions so sideways phone footage is not silently treated as unrotated.
- **Application semantics are excluded.** TwinForge models only observed physical geometry and reconstruction provenance.
